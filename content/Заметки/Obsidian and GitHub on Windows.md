# Цель
Организовать свой блог из заметок, которыми хочу поделиться, не создавая при этом нового, отдельного хранилища.

Система должна быть автоматизирована, чтобы получать задуманный результат без сложных действий и манипуляций с файлами. Иначе, проще делать ручной экспорт и публикацию копированием.

Кроме публичных файлов, остальные файлы не должны храниться на хостингах и облачных дисках.

Блог должен быть на моём домене. В случае, если доступ к хостингу будет потеряна, я должен иметь возможность развернуть сайт, без потери данных на другом сервисе.


# Решение

## Выбор вариантов

Я не программист и не IT специалист. Поэтому для меня большая часть описанного ниже было бы не возможно без искусственного интеллекта. Все решения были навеяны рекомендациями парочки чатов с ИИ.

При этом я всё же провел исследование, изучив статьи и видео на Youtube, чтобы сориентироваться в возможных вариантах. В итоге пришлось делать свой, на основе предложенных другими пользователями.

**Остальные мне не подошли по следующим причинам:**
- *Файлы хранятся не на моем компьютере (как например с полной синхронизацией на GitHub).*
- *Создание отдельной папки для публичных заметок или даже отдельного хранилища Obsidian. Что для меня просто не удобно.*
- *Использование нескольких сервисов, плагинов и приложений, в каждом из которых нужно разбираться*

## Моё решение

Нельзя сказать, что моё решение идеальное. А главное, оно требует индивидуального, не общедоступного решения. Но я приложу всё необходимое и опишу весь процесс.

Чтобы понимать, стоит ли читать дальше, то вот как это будет работать:
- Моё решение адаптировано под Windows (ИИ легко адаптирует под другие ОС).
- У вас одна база (хранилище) Obsidian в которой хранятся все заметки.
- Плагин в Obsidian запускает скрипт для PowerShell который выборочно копирует файлы напрямую из директории хранилища, в директорию, из которой будет собираться блог, обновляя прошлые версии.
- Я не решаю вопрос синхронизации файлов с телефоном или между устройствами. Этот вопрос у меня решен при помощи [[SyncThing]], что меня более чем устраивает.
- В итоге мы получим блог или базу знаний из части собственных заметок, лежащих по личному URL адресу в интернете.
- Процесс будет автоматизирован. А ваши файлы будут на вашем компьютере.

## Настройка

Для настройки синхронизации потребуется:

- **Аккаунт на GitHub**
- **Скрипт** - [[publish.ps1|файл с командами для PowerShell Windows]]
- **Установленный Git** - для командной строки
- **Плагин Obsidian** - Shell commands
- **Node.js** - для сборки сайта перед выгрузкой [Выбрать последнюю версию](https://nodejs.org/dist/)


Собственно это всё. настройка может показаться очень сложной, особенно для людей не занимающихся системным администрированием компьютеров и программированием. Но если делать всё по инструкции, то это будет быстро.
