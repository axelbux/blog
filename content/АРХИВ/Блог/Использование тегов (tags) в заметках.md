### Теги должны использоваться как признак заметки и отвечать следующим правилам:
1. Тег отвечает на вопрос, адресованный заметке - что это? Или кто это?
2. Для группировки заметок по этому признаку не требуется создания обобщающей заметки верхнего уровня по типу MOC (Map of content), так как свойство связывающее их не раскрывается в отдельную тему для изучения. 

Например:
- **контакт** - заметки с контактами людей.
- **тренировка** - заметки с тренировками.
- **задача** - задачи по проектам.
- **идея** - мысли, еще не ставшие заметкой, которые требуют дальнейшего анализа и изучения, а  также регулярно возращения к ним. Тег упрощает быстрый поиск идей в хранилище заметок.
- **контент/сценарий, контент/стихи, контент/статья** - для быстрого поиска и маркировки заметок с контентом.
- **бизнес** - для объединения по признаку, заметок связанных с бизнесом.
- **итоги, итоги/месяц, итоги/квартал, итоги/год** - иерархия тегов, для быстрого доступа к заметкам с итогами. ==Это атавизм прошлой системы, требует пересмотра.==
- **аналитика** - заметки посвященные глубокому анализу какой либо темы.
- **здоровье** - для быстрого поиска заметок с рецептами и другой информацией. Отдельной заметки для этого не требуется, так как это справочная информация для записной книжки.
- **архив** - используется для пометки заметок, с которых плагину DataView не надо собирать ToDo задачи в списки задач. Обозначает, что заметка находится на хранении, но активной работы с ней не производится. Например списки фильмов, подарков и т.д.

Новые теги создаются в том случае, если уже существующие не подходят, для объединения заметок по признаку.
